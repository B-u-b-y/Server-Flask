Make sure to have installed:
- flask-cors `.venv\Scripts\pip install flask-cors` 
- pymongo `.venv\Scripts\pip install pymongo` 
- pandas `.venv\Scripts\pip install pandas` 
- matplotlib `.venv\Scripts\pip install matplotlib` 
- geopandas `.venv\Scripts\pip install geopandas`

Only when you have installed all the packages you can run the server by typing `.venv\Scripts\python app.py`
